Como usar estos bloques

1. Carga MatiasUI

<link rel="stylesheet" href="/dist/matias-ui.css">
<script defer src="/dist/matias-ui.js"></script>

2. Copia un bloque

Usa el preview como base, cambia textos, datos e imagenes, y conserva clases `mui-*`.

3. Activa interacciones

data-mui-open-modal="#id"
data-mui-dropdown
data-mui-accordion
data-mui-copy="#snippet"

4. Personaliza tokens

:root {
  --mui-primary: #c1123f;
  --mui-accent: #0f766e;
}
