## Que incluye

- `dist/matias-ui.css`: estilos, tokens, componentes y utilidades.
- `dist/matias-ui.js`: interacciones progresivas con atributos `data-mui-*`.
- `examples/`: paginas de prueba completas como dashboard, ecommerce y tarjeta credito/debito.
- Documentacion Starlight con guias, referencia, bloques y snippets.

## Filosofia

MatiasUI no intenta controlar tu aplicacion. Te da una capa visual y de comportamiento liviana, portable y facil de inspeccionar. Puedes copiar HTML, adaptar clases y mantener tu backend o framework favorito.
