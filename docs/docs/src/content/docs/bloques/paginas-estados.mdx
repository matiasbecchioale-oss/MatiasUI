---
title: Paginas y estados
description: Estados de sistema para experiencias completas.
---

MatiasUI cubre estados comunes de aplicaciones y sitios:

- 404
- 500
- Maintenance
- Empty states
- Loading skeleton
- Success confirmation
- Error alerts
- Popups

```html
<section class="mui-empty">
  <span class="mui-badge">Sin datos</span>
  <h2>No hay resultados</h2>
  <p class="mui-muted">Cambia los filtros o crea un nuevo registro.</p>
  <button class="mui-btn mui-btn-primary">Crear</button>
</section>
```
