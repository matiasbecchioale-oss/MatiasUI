MatiasUI incluye bloques originales para construir paginas de marketing completas.

## Bloques

- Hero sections
- Feature sections
- Pricing tables
- CTA sections
- Testimonials
- FAQ accordions
- Contact forms
- Newsletter forms
- Team, logos y portfolio
- Banners, popups y event schedule

```html
<section class="mui-hero">
  <div class="mui-container mui-split">
    <div class="mui-stack">
      <span class="mui-badge">Nuevo</span>

      <p class="mui-subtitle">Una landing lista para convertir.</p>
      <button class="mui-btn mui-btn-primary">Empezar</button>
    </div>
    <div class="mui-hero-media"></div>
  </div>
</section>
```
