---

## CDN npm

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/matias-ui@1/dist/matias-ui.css">
<script defer src="https://cdn.jsdelivr.net/npm/matias-ui@1/dist/matias-ui.js"></script>
```

## CDN propio

```html
<link rel="stylesheet" href="https://tu-dominio.com/matias-ui/matias-ui.css">
<script defer src="https://tu-dominio.com/matias-ui/matias-ui.js"></script>
```

## Recomendacion

Para produccion, versiona la ruta (`@1`, `@1.1.0` o una carpeta propia) para evitar cambios inesperados.
