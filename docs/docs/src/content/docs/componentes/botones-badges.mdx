title: Botones y badges
description: Acciones, estados y etiquetas.

```html
<button class="mui-btn">Default</button>
<button class="mui-btn mui-btn-primary">Primary</button>
<button class="mui-btn mui-btn-soft">Soft</button>
<button class="mui-btn mui-btn-ghost">Ghost</button>
<button class="mui-btn mui-btn-icon">+</button>
```

```html
<span class="mui-badge">Nuevo</span>
<span class="mui-badge mui-badge-success">Activo</span>
<span class="mui-badge mui-badge-warning">Pendiente</span>
<span class="mui-badge mui-badge-danger">Error</span>
```

Usa `mui-chip` para filtros y metadatos compactos.
