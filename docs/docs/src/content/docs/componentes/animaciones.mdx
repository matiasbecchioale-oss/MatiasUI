## Utilidades

- `mui-animate-fade`
- `mui-animate-slide-up`
- `mui-animate-pop`
- `mui-animate-pulse`
- `mui-animate-float`
- `mui-animate-glow`
- `mui-animate-tilt`
- `mui-animate-shake`
- `mui-animate-scale`
- `mui-marquee`

```html
<article class="mui-card mui-animate-pop">
  Aparece con animacion.
</article>
```

MatiasUI respeta `prefers-reduced-motion` para reducir animaciones en usuarios que lo pidan.
