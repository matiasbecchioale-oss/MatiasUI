---
title: Interacciones
description: Atributos data-mui disponibles.
---

MatiasUI usa JavaScript progresivo: si no lo cargas, el CSS sigue funcionando.

| Atributo | Uso |
| --- | --- |
| `data-mui-nav` | Contenedor de navbar responsive |
| `data-mui-nav-toggle` | Boton que abre/cierra nav mobile |
| `data-mui-dropdown` | Dropdown o menu |
| `data-mui-open-modal="#id"` | Abre modal |
| `data-mui-close-modal` | Cierra modal |
| `data-mui-tabs` | Tabs |
| `data-mui-accordion` | Acordeones |
| `data-mui-toast="Mensaje"` | Dispara toast |
| `data-mui-theme-toggle` | Alterna tema |
| `data-mui-copy="#id"` | Copia snippets |
| `data-mui-live` | Playground live |
| `data-mui-open-drawer="#id"` | Abre drawer |
| `data-mui-dismiss=".selector"` | Cierra alertas/popups |
| `data-mui-count-to="100"` | Contador animado |
| `data-mui-search-focus` | Foco con tecla `/` |
