## Clases principales

- `mui-body`: base visual del documento.
- `mui-container`: ancho maximo centrado.
- `mui-section` y `mui-section-sm`: espaciado vertical.
- `mui-stack`: columna con gap configurable.
- `mui-cluster`: fila flexible con wrap.
- `mui-grid`, `mui-grid-2`, `mui-grid-3`, `mui-grid-4`: grids responsive.
- `mui-split`: dos columnas para hero o layouts editoriales.

```html
<section class="mui-section">
  <div class="mui-container mui-grid mui-grid-3">
    <article class="mui-card">Uno</article>
    <article class="mui-card">Dos</article>
    <article class="mui-card">Tres</article>
  </div>
</section>
```
