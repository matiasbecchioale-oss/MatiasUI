File tree

Estructura recomendada para usar MatiasUI como libreria local, CDN o paquete npm.

  • matias-ui/
    • dist/
      • matias-ui.css
      • matias-ui.js
    • docs/
      • index.html
      • components.html
      • snippets.html
      • live.html
      • animations.html
    • examples/basic.html
    • README.md
    • package.json

Instalacion recomendada

Para Astro o cualquier framework, copia `dist/` a `public/matias-ui/` o importa desde npm cuando publiques.

El CSS es independiente. El JS solo suma interacciones.
